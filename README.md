## Running the game

The main thing you need to run the game is [Rust](https://rust-lang.org/learn/get-started/).

After Rust is installed, you should be able to use the `cargo` command in the terminal.

Open a terminal, and navigate to the directory that the game is in.

Once there, run the game with `cargo run`. It will take a few minutes to compile
the first time.

To stop the game, you can either close the window, or press CTRL+C in the
terminal. It can be started again with `cargo run`.
